# Reproducibility checklist

- Version tools, containers and reference databases.
- Freeze input manifests and retrieval dates per release.
- Keep QC thresholds and taxonomic criteria in tracked configuration.
- Track raw-read and assembly-only paths separately.
- Retain provenance and deduplication decisions.
- Use toy datasets for CI; avoid public sequence bulk files in Git.
- Record pipeline parameters, checksums and release identifiers.
